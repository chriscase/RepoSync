For each, this says what v1.1 or v1.2 had already changed, what v1.3 changes, the result as of v1.3, and where. Nothing is disputed: every source claim in the review was re-checked against both epic tips and found correct.

The review asked for a version called v1.1. That number and v1.2 were already used for the versions that applied Chris's decisions, so the answer was v1.3. v1 is unchanged.

This file was written for v1.3 and its “As of v1.3” column is kept as it was, with one correction: the follow-up review found F8 only partly fixed. It also found residuals in F2, F6 and F14. [CHANGES-FROM-v1.3.md](CHANGES-FROM-v1.3.md) records what v1.4 did about them.

## Changes between v1 and this version that do not come from the review

They come from Chris's decisions and are listed in [CHANGES.md](CHANGES.md) and [DECISIONS.md](DECISIONS.md): dark by default, light in all six layouts, the “More” control after the last workspace link, one appearance for sign-in, the text catalogue, pages keeping today's order of regions, the colour bridge, and `?section=` on the repository page.

## Not done, as of v1.3

As of v1.3 the designer had rendered nothing, on the belief that no sandboxed browser could start in the container; that was wrong for a non-root user, and the package index describes the check that now runs. When v1.3 was written the publisher had rendered v1 and v1.2. It has since captured every later version, including the `-menu` fragment under F12 and the layout corrections under F13; the package index records those runs.
