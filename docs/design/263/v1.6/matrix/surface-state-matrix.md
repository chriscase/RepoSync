# Surface and state matrix

140 rows: every route G01 to G13 and every surface that has no route of its own. **124 covered, 15 explicit gap, 1 not applicable.** No cell is blank.

The same rows are in [surface-state-matrix.csv](surface-state-matrix.csv) and [surface-state-matrix.json](surface-state-matrix.json). Those two files carry the twelve reference columns in full: three options, light and dark, 1440×900 and 390×844.

## How to read it

- **Epic and source.** Line numbers were resolved by script against `b2b055a72657824fd6662b451f69718d73405aa5` (epic/reposync-partial-52) and `5853a8884496d294ce21898415d7d2718b73bf7c` (epic/reposync-reliability-61). The line is the first occurrence of the quoted symbol or text in the file at that revision. Paths without a root are under `web-ui/src/`.
- **Where the epics differ.** Three rows: G02.8 and G04.16 (commit map target cell) and G04.6 (path policy editor). Each describes both.
- **Prototype pages.** Each page name exists under all three options. L, C and G open the Ledger, Console and Guide page. Add `#light` or `#dark` to the address to fix the theme; add `-nobar` (for example `#dark-nobar`) to hide the grey prototype bar.
- **References are pages.** Each reference is one responsive page. The 1440×900 and 390×844 columns hold the same address because the width is the viewport, not a different file. The publisher's captures of a page are named `<option>_<page>__<theme>__<wide|narrow>.png`, for example `ledger_g04-overview__dark__narrow.png`; the package itself carries no pictures.
- **Kind** says how the drawn page relates to today's product:

  **existing** (73 rows). Kept as it is.

  **existing, known defect** (24 rows). Kept. The page draws a correction that is separate work; without it the option shows today's behaviour.

  **design proposal** (28 rows). Kept, with the wording or presentation proposal in the note.

  **held or unsupported** (5 rows). Shown as held or unavailable, with no control that acts.

  **needs separately owned feature work** (10 rows). A gap. Drawn and marked, and not counted as parity.

- **For #264** says what kind of work the row is: *layout only*, *shell extension* (one of four accepted changes to the #262 shell), *shared change, with the layouts* (display only), *shared change, own change* (changes when a call is made or adds a step), *waits for an owner*, or *feature work* (outside #264). See the implementation map.
- **Status.** *Covered*: the surface and its states are drawn in every option, theme and size. *Explicit gap*: the product cannot do this today, or a decision is open; the page marks it and the note says why. *Not applicable*: nothing to draw, with the reason.
